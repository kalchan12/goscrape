# ScrapePull

A web scraping CLI tool built with Go.

## Features

- Web scraping with Colly and Chromedp (JS-rendered pages)
- TUI interface built with Bubble Tea
- SQLite storage for scraped data
- Progress bars and logging

## Usage

```bash
go run main.go [command] [flags]
```

## Build

```bash
go build -o scrapepull .
```
